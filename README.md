# AIA CI Plan Calculator

Aplikasi web kalkulator ilustrasi CI Plan Pampasan Sakit Kritikal dengan tema merah jambu/merah AIA.

## Kandungan
- `index.html` — aplikasi utama.
- `assets/aia-mountain-logo.jpeg` — logo AIA gunung di bahagian atas.
- `assets/aia-public-takaful-logo.png` — logo AIA Public Takaful di profil ejen.
- `assets/agent-profile-photo.jpg` — gambar profil ejen.
- Imej rujukan kadar dan penerangan CI Plan.

## Cara guna
1. Muat turun dan ekstrak ZIP.
2. Untuk GitHub, muat naik semua kandungan folder ini (pastikan folder `assets` turut dimuat naik).
3. Pastikan `index.html` berada di root repository.
4. Sambungkan repository ke Vercel atau deploy semula projek sedia ada.

## Nota penting
Kadar kalkulator berdasarkan jadual rujukan yang dibekalkan. Dalam jadual rujukan yang tersedia, kadar hanya dipaparkan untuk lelaki merokok dan wanita tidak merokok. Untuk kombinasi lain, aplikasi meminta pengguna merujuk jadual rasmi dan tidak mereka angka. Sahkan semua kadar, manfaat, terma, pengecualian dan kelayakan dengan AIA Public Takaful sebelum digunakan sebagai cadangan rasmi.
